# Manga Reader

漫蛙漫画阅读器（首页/分类/详情/阅读器） + Vercel 代理

## 部署

1. Fork 本仓库
2. 连接 [Vercel](https://vercel.com/new/clone?repository-url=https://github.com/dickisz1/manga-reader)
3. 环境变量：无需配置
4. 部署完成

## 使用

- 首页/书架 → 分类/发现 → 漫画详情 → 阅读器
- 阅读器支持：章节列表、亮度/字体/主题设置、键盘翻页
- 图片走代理中转，绕过 Cloudflare

## 注意事项

- 数据来源：manwaxu.cc
- 仅本地浏览，不存储用户数据
